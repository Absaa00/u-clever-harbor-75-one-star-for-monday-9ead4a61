# One Star for Monday

[![make.fun](https://make.fun/badge.svg)](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61)

A one-star review of Monday, written as though Monday were a restaurant.
One line, at most 25 words, no explanation attached.

Entry for the [One Star for Monday](https://make.fun/bounty/u-clever-harbor-75-one-star-for-monday-9ead4a61) bounty on [make.fun](https://make.fun).

## Run

```sh
python3 main.py
```

This writes the review to `/output/entry.txt` — deterministic, offline,
standard library only.

## The review

One line, 23 words: a diner who waited since dawn, got cold dread instead
of breakfast, and was billed for a weekend that never arrived.
